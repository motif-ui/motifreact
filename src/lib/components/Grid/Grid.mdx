`<Grid>` is used to provide an easy placement for items in the page. It is mainly based well accepted standards of
Bootstrap, and it's grid system. It basically divides the container into **12** equal pieces. It is possible to tell
`<Grid>` the number of columns to contain, considering the container size.

Page size aliases alongside with the container sizes are:

    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**xl**</td><td>>= 1200px</td><td>1140px</td>
    </tr>
    <tr>
      <td>**lg**</td><td>>= 992px</td><td>960px</td>

      <td>**md**</td><td>>= 768px</td><td>720px</td>
    </tr>
    <tr>
      <td>**sm**</td><td>>= 576px</td><td>540px</td>
    </tr>
    <tr>
      <td>**xs**</td><td>>= 384px</td><td>360px</td>
    </tr>
     <tr>

The **minimum** supported width of the `<Grid>` is **420px** even if the width below 384px is considered as `xxs`.
Most of the contents below 420px might still look good, but it isn't `<Grid>`'s responsibility.

`<Grid>` itself is a pretty simple component which only accepts `<Grid.Row>` as children. In order to correctly place the
content, it provides two additional components to help:

<br />

### `<Grid.Row>`

**Row** is the wrapper for those 12 columns mentioned above. It (literally) provides a row container which only
allows `<Grid.Col>` as children.

#### Justify

Alignment of the content can be set using `<Grid.Row>` in case all 12 columns are not filled.

```tsx
<Grid.Row justifyCols="center">...</Grid.Row>
```

<GridComponent style={{ background: "#FFFFFF", padding: 24, border: "2px solid #f6f7fb", borderRadius: 22 }} colProps={{ style: { border: "solid 1px #CCC" } }}>
  <Row justifyCols="center">
    <Col size={2}>My content</Col>
  </Row>
</GridComponent>

#### colsAuto

By default, given Cols are disributed evenly if there is no size given. But it is also possible to distribute the Cols
depending on their content. **colsAuto** is used for this.

```tsx
<Grid.Row colsAuto>...</Grid.Row>
```

<GridComponent style={{ background: "#FFFFFF", padding: 24, border: "2px solid #f6f7fb", borderRadius: 22 }} colProps={{ style: { border: "solid 1px #CCC", margin: 1 } }}>
  <Row colsAuto>
    <Col>My short content</Col>
    <Col>My medium medium content</Col>
    <Col>My long long long long long long content</Col>
  </Row>
</GridComponent>

#### stretchItems

Cols in the same row always have equal heights, but their content keeps its own size. **stretchItems** stretches the
content of each Col to fill it, which is useful for showing cards with equal heights.

```tsx
<Grid.Row stretchItems>...</Grid.Row>
```

<GridComponent style={{ background: "#FFFFFF", padding: 24, border: "2px solid #f6f7fb", borderRadius: 22 }}>
  <Row stretchItems>
    <Col size={4}><div style={{ border: "solid 1px #CCC" }}>My short content</div></Col>
    <Col size={4}><div style={{ border: "solid 1px #CCC" }}>My long long long long long long long long long long long long long long content</div></Col>
    <Col size={4}><div style={{ border: "solid 1px #CCC" }}>My medium medium content</div></Col>
  </Row>
</GridComponent>

<br />

### `<Grid.Col>`

The most important component in the grid system is `<Grid.Col>`. This component is the container of the real content.
**size** prop can be used in order to set the number of columns that needs to be filled. It is basically the width of
the content in terms of columns.

```tsx
<Grid.Col size={3}>Three column content</Grid.Col>
<Grid.Col size={6}>Six column content</Grid.Col>
```

<GridComponent style={{ background: "#FFFFFF", padding: 24, border: "2px solid #f6f7fb", borderRadius: 22 }} colProps={{ style: { border: "solid 1px #CCC", margin: 1 } }}>
  <Row>
    <Col size={3}>Three column content</Col>
    <Col size={6}>Six column content</Col>
  </Row>
</GridComponent>

<br />
`<Grid.Col>` is highly customizable. There are 4 different size aliases that may change the number of columns to be covered.

Each size prop sets the number of columns for the related minimum width and above. Bigger size prop always overrides the
smaller ones. For example when `md={6}` and `sm={12}`, there will be 12 columns if page is **sm** or wider. If page is
wider then the **md** size, then there will be 6 columns.

Please refer to the example below. If the page is **md**, then the columns should be distributed as 6-6. If the page is
smaller and refers to the size of **sm**, then the content should fill all 12 columns. If the page is smaller than **sm**,
then the content should be distributed as 4-8.

In order to check this example, you may want resize you browser to change the width of the container.

```tsx
<Grid.Col size={4} md={6} sm={12}>My content</Grid.Col>
<Grid.Col size={8} md={6} sm={12}>Your content</Grid.Col>
```

<GridComponent style={{ background: "#FFFFFF", padding: 24, border: "2px solid #f6f7fb", borderRadius: 22 }} colProps={{ style: { border: "solid 1px #CCC", margin: 1 } }}>
  <Row>
    <Col size={4} md={6} sm={12}>My content</Col>
    <Col size={8} md={6} sm={12}>Your content</Col>
  </Row>
</GridComponent>

All size props are optional. `<Grid.Col>` fills the remaining space if no size props are given.

```tsx
<Grid.Col size={4}>My content</Grid.Col>
<Grid.Col>I am filling it!</Grid.Col>
```

<GridComponent style={{ background: "#FFFFFF", padding: 24, border: "2px solid #f6f7fb", borderRadius: 22 }} colProps={{ style: { border: "solid 1px #CCC", margin: 1 } }}>
  <Row>
    <Col size={4}>My content</Col>
    <Col>I am filling it!</Col>
  </Row>
</GridComponent>

### Nesting

A `<Grid.Col>` may contain `<Grid.Row>`s, to split it into columns again. The nested Rows size their own Cols, and their
gaps are taken from the Grid unless they are given. Nested Rows are separated by the vertical gap of the Row containing
the Col.

```tsx
<Grid>
  <Grid.Row rowGap="md">
    <Grid.Col size={12} md={8}>
      <Grid.Row>...</Grid.Row>
      <Grid.Row gap="xs">...</Grid.Row>
    </Grid.Col>
  </Grid.Row>
</Grid>
```

Use a nested `<Grid>` instead, when the nested part needs its own padding, default gaps or **colProps**.

### Gap

The space between Cols is set using 3 props, on both `<Grid>` and `<Grid.Row>`:

- **gap**: the space between Cols, both horizontally and vertically
- **columnGap**: the horizontal space between side by side Cols. Takes precedence over **gap**
- **rowGap**: the vertical space between Cols wrapped onto a new line. Takes precedence over **gap**

On `<Grid>`, the vertical space is also used as the space between Rows. Col sizes are always calculated with the
horizontal space of their row. Gaps do not change the padding of the Grid, see [Padding](#padding).

All of them accept a gap size alias, `"xxs"` to `"xxl"`, or `"none"` for no space. Default is `"sm"`.

```tsx
<Grid gap="md">...</Grid>
<Grid gap="md" rowGap="xl">...</Grid>
```

#### Responsive gaps

The gap can be changed depending on the page size by giving an object with the keys **base**, **xsUp**, **smUp**,
**mdUp**, **lgUp**, **xlUp** and **xxlUp**. **base** is the smallest page size and the starting point. Each of the
others applies to its page size **and above**, e.g. **mdUp** applies to **md**, **lg**, **xl** and **xxl**. So a page
size without a value takes the value of the closest smaller page size, and it is not needed to give all of them.

```tsx
// base, xs, sm => "sm" | md, lg, xl, xxl => "xl"
<Grid gap={{ base: "sm", mdUp: "xl" }}>...</Grid>
```

To have a value up to a page size, give it as **base**, and give the other value for the next page size:

```tsx
// md and below => "xl" | lg and above => "xxl"
<Grid gap={{ base: "xl", lgUp: "xxl" }}>...</Grid>
```

When a value is not given for a page size and any smaller page sizes, it is taken from the upper level. A Row takes the
value of its Grid, and a Grid uses the default value.

```tsx
<Grid gap={{ base: "sm", lgUp: "xl" }}>
  {/* base, xs, sm => "sm" (from Grid) | md, lg, xl, xxl => "xxl" */}
  <Grid.Row gap={{ mdUp: "xxl" }}>...</Grid.Row>
  {/* "md" on every page size, overrides the Grid's values */}
  <Grid.Row gap="md">...</Grid.Row>
</Grid>
```

**columnGap** and **rowGap** always take precedence over **gap**, on every page size. For example, the horizontal space
below is `"xs"` on **md**, since **columnGap** has a value for **smUp**:

```tsx
<Grid gap={{ mdUp: "xl" }} columnGap={{ smUp: "xs" }}>...</Grid>
```

  <Row>
    <Col size={4}>Resize the page</Col>
    <Col size={4}>Resize the page</Col>
    <Col size={4}>Resize the page</Col>

#### Custom values

Values out of the gap size aliases can be given using CSS variables. Each prop and page size has its own variable,
named as `--mtf-grid-{pageSize}-{prop}` with the plain page size name, e.g. `--mtf-grid-lg-gap` for **lgUp**:

<table>
  <thead>
    <tr>
      <th>Prop</th><th>CSS variables</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**gap**</td><td>`--mtf-grid-base-gap`, `--mtf-grid-xs-gap` ... `--mtf-grid-xxl-gap`</td>
    </tr>
    <tr>
      <td>**rowGap**</td><td>`--mtf-grid-base-row-gap`, `--mtf-grid-xs-row-gap` ... `--mtf-grid-xxl-row-gap`</td>
    </tr>
    <tr>
      <td>**columnGap**</td><td>`--mtf-grid-base-column-gap`, `--mtf-grid-xs-column-gap` ... `--mtf-grid-xxl-column-gap`</td>
    </tr>
  </tbody>
</table>

They work exactly like the props, so no media queries are needed. Set them on the `<Grid>` or `<Grid.Row>` itself, they
are not inherited by nested Grids and Rows. Do not set `column-gap` directly, since Col sizes are calculated with these
variables.

```css
.hero {
  --mtf-grid-base-gap: 30px;
  --mtf-grid-lg-gap: 120px;
}
```

```tsx
<Grid className="hero">...</Grid>
```

### Padding

The padding of `<Grid>` is set on all sides using **padding**. It accepts the same values as **gap**, including `"none"`
and the responsive object, and it is independent of the gaps. Default is `"sm"`.

```tsx
<Grid padding="xl">...</Grid>
<Grid padding="none">...</Grid>
<Grid gap="xs" padding={{ base: "none", lgUp: "xxl" }}>...</Grid>
```

Custom values are given with the `--mtf-grid-{pageSize}-padding` CSS variables, exactly like the [custom gap values](#custom-values),
so no media queries are needed. Below, the padding is `"lg"` up to **md**, and `120px` on **md** and above:

```css
.hero {
  --mtf-grid-md-padding: 120px;
}
```

```tsx
<Grid className="hero" padding="lg">...</Grid>
```

**The default padding will be `"none"` in the next major version.** To keep the current padding after that, or to switch
to the new default now, set it globally with `componentDefaults` of `MotifProvider`:

```tsx
<MotifProvider componentDefaults={{ Grid: { padding: "sm" } }}>...</MotifProvider>   // keeps the current padding
<MotifProvider componentDefaults={{ Grid: { padding: "none" } }}>...</MotifProvider> // switches to the new default
```

### Upcoming: fluid by default

`<Grid>` currently limits its width to the container max-width of the screen size, unless **fluid** is set. **Grid will
be fluid by default in the next major version**, and the **fluid** prop will be removed. The container max-widths are
already provided by `<Container>`, so for the main layout of a page, use a fluid `<Grid>` in a `<Container>`. It will
keep working the same after the change:

```tsx
<Container>
  <Grid fluid>...</Grid>
</Container>
```

A Grid nested in a Col or a Panel will not need **fluid** anymore after the change.

### Deprecated `leanToEdge`

**leanToEdge** prop is deprecated and will be removed in the next major version. Use `padding="none"` instead.

### Deprecated `gutter`

**gutter** prop is deprecated and will be removed in the next major version. It sets both the gap and the padding, so `gutter="lg"` is equal to
`gap="lg" padding="lg"`. It is still supported as the lowest priority value: it is used only for the page sizes that
**gap**, **rowGap**, **columnGap** and **padding** have no value for.
