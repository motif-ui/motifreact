# Support

Need help with **Motif UI**? Here's where to look and how to reach us, depending on what you need.

<br />

## 1. Check the Documentation First

Most questions about installation, theming, localization, and component usage are already covered in this Storybook
documentation. Before opening an issue, please make sure your question isn't already answered here.

- 🌐 Project website: [motif-ui.com](https://motif-ui.com)

Good starting points if you are unsure where to look:

- <a href="../?path=/docs/getting-started-installation--docs">**Getting Started/Installation**</a> for setup issues
- <a href="../?path=/docs/customization-guide--docs">**Customization/Guide**</a> for theming and styling questions
- <a href="../?path=/docs/utility-utility-functions--docs">**Utility/Utility Functions**</a> for helper function references

## 2. Reporting a Bug

If you found a bug, please open an issue on our GitHub repository using the **Bug Report** template. Before submitting,
search the [open and closed issues](https://github.com/motif-ui/motifreact/issues?q=is%3Aissue) to check if it has
already been reported.

👉 [Open a Bug Report](https://github.com/motif-ui/motifreact/issues/new?template=bug_report.yml)

To help us fix it quickly, please include:

- A clear description of the bug
- The affected component(s) (e.g. `Button`, `Checkbox`)
- Steps to reproduce the issue
- Your environment (OS, browser, npm/node versions)
- Any relevant console or server logs

## 3. Requesting a Feature

Have an idea that would make Motif UI better? We'd love to hear it. Feature requests are tracked the same way as bugs,
through GitHub issues.

👉 [Open a Feature Request](https://github.com/motif-ui/motifreact/issues/new?template=feature_request.yml)

Please describe what you'd like to see and, if applicable, which existing component(s) it relates to.

> **Note:** We don't accept blank issues. Please always use the **Bug Report** or **Feature Request** template so we
> have enough context to act on it.

## 4. Contributing

Motif UI is built and maintained together with its community. If you'd like to fix a bug yourself, build a new
component, or improve the documentation, check out our [Contributing Guidelines](https://github.com/motif-ui/motifreact/blob/main/.github/CONTRIBUTING.md)
for the development setup, project structure, coding rules, and PR title conventions.

<br />

All contributors are expected to follow our [Code of Conduct](https://github.com/motif-ui/motifreact/blob/main/.github/CODE_OF_CONDUCT.md).
