# Blocks

Blocks are guides that show how Motif UI components work together to build real-world UI sections. Where a component
solves a single UI need (a button, an input, a panel), a block demonstrates how several components are combined into a
complete piece of an interface, such as a login screen or a registration form. Use them as a starting point to build your
website or app faster.

## How to Use a Block

Blocks are not shipped inside the `@motif-ui/react` package, as they are not extra components. Each block is provided
as source code built only with Motif UI components, so you can copy it and have full control over it.

1. Make sure Motif UI is [installed](?path=/docs/getting-started-installation--docs) and your app is wrapped with
   [`MotifProvider`](?path=/docs/getting-started-motifprovider--docs).
2. Open the block's page from the menu and expand its source files below the preview.
3. Copy the files into your project.
4. Replace the placeholder parts with your own content: the logo, texts and link URLs.

Blocks are built only with the public Motif UI API, so a copied block imports its components from `@motif-ui/react`
just like the rest of your app:

```tsx
// src/blocks/Login.tsx
import { BusinessCard, Form, InputPassword, InputText, Panel, Validations } from "@motif-ui/react";

const Login = () => (
  <Panel bordered>
    <BusinessCard title="Log in to your account" description="Enter your credentials to access your account" />
    <Form onSubmit={() => {}} submitButtonLabel="Log In" buttonPosition="fluid">
      <Form.Field name="email" label="Email Address" validations={[Validations.Required, Validations.EMAIL]}>
        <InputText iconLeft="mail" placeholder="you@example.com" />
      </Form.Field>
      <Form.Field name="password" label="Password" validations={[Validations.Required]}>
        <InputPassword iconLeft="lock" toggleMask placeholder="Enter your password" />
      </Form.Field>
    </Form>
  </Panel>
);

export default Login;
```

Then use it anywhere in your app like any other React component:

```tsx
import Login from "./blocks/Login";

export default function LoginPage() {
  return <Login />;
}
```

## Customizing a Block

Once copied, a block is plain React code. Change it however you need:

- **Content:** Edit titles, descriptions, labels and placeholders directly in the code.
- **Behavior:** Add or remove fields and adjust [validations](?path=/docs/form-validation--docs) to fit your rules.
- **Assets:** Logos and images in the blocks point to Motif UI assets. Replace them with your own brand assets.
