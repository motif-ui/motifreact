# useToggle

Manages visibility states with optional animation support.

## Basic Usage

```jsx
import { useToggle } from "@motif-ui/react";

const Sidebar = () => {
  const { visible, show, hide, toggle } = useToggle();

  return (
    <>
      <button onClick={toggle}>Toggle Sidebar</button>
      {visible && <div>Sidebar content</div>}
    </>
  );
};
```

## With Animation

Use `duration` to match the hook's timing to your CSS transition length.
`visible` becomes `true`/`false` right away for both `show()` and `hide()`, so CSS transitions trigger immediately.
`toggleState` stays set for `duration` ms afterward so the element can remain mounted while the transition plays.

```jsx
import { useToggle } from "@motif-ui/react";

const AnimatedModal = () => {
  const { visible, toggleState, show, hide } = useToggle({ duration: 300 });
  const attached = visible || !!toggleState;

  return (
    <>
      <button onClick={show}>Open Modal</button>
      {attached && (
        <div className={visible ? "fade-in" : "fade-out"}>
          Modal content
          <button onClick={hide}>Close</button>
        </div>
      )}
    </>
  );
};
```

## Animation Pattern

When `options` is provided:

**Enter (`show()`):**

1. `toggleState` becomes `"showing"` — mounts the element while it's still hidden
2. On the next frame, `visible` becomes `true` — CSS enter transition triggers
3. After `duration` ms, `toggleState` becomes `undefined`

**Exit (`hide()`):**

1. `visible` becomes `false` immediately — CSS exit transition triggers at once
2. `toggleState` becomes `"hiding"` — keeps the element mounted
3. After `duration` ms, `toggleState` becomes `undefined` — element can be unmounted

Use `attached = visible || !!toggleState` to control mounting:

```jsx
const { visible, toggleState, show, hide } = useToggle({ duration: 300 });
const attached = visible || !!toggleState;

// attached: mount/unmount gate
// visible:  CSS class gate (triggers enter/exit transitions)
```
