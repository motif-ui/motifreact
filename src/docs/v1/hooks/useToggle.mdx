# useToggle

Manages visibility states with optional animation support.

## Basic Usage

```jsx
import { useToggle } from "@motif-ui/react";

const Sidebar = () => {
  const { visible, show, hide, toggle } = useToggle(false);

  return (
    <>
      <button onClick={toggle}>Toggle Sidebar</button>
      {visible && <div>Sidebar content</div>}
    </>
  );
};
```

## With Animation

Use `showTime` and `hideTime` to control animation durations independently.
`visible` becomes `false` immediately when `hide()` is called, so CSS exit transitions trigger at once.
The element stays mounted for `hideTime` ms to let the animation complete.

```jsx
import { useToggle } from "@motif-ui/react";

const AnimatedModal = () => {
  const { visible, toggleState, show, hide } = useToggle(false, { showTime: 50, hideTime: 300 });
  const attached = visible || !!toggleState;

  return (
    <>
      <button onClick={show}>Open Modal</button>
      {attached && (
        <div className={visible ? "fade-in" : "fade-out"}>
          Modal content
          <button onClick={hide}>Close</button>
        </div>
      )}
    </>
  );
};
```

## Animation Pattern

When `options` is provided:

**Enter (`show()`):**

1. `toggleState` becomes `"showing"`
2. After `showTime` ms, `visible` becomes `true` and `toggleState` becomes `undefined`

**Exit (`hide()`):**

1. `visible` becomes `false` immediately — CSS exit transition triggers at once
2. `toggleState` becomes `"hiding"` — keeps the element mounted
3. After `hideTime` ms, `toggleState` becomes `undefined` — element can be unmounted

Use `attached = visible || !!toggleState` to control mounting:

```jsx
const { visible, toggleState, show, hide } = useToggle(false, { showTime: 50, hideTime: 300 });
const attached = visible || !!toggleState;

// attached: mount/unmount gate
// visible:  CSS class gate (triggers enter/exit transitions)
```
